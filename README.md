# 💧 自來水公司3D大亂鬥：罪惡營業處（Grand Theft Water Corp 3D）

受《俠盜獵車手（GTA）》系列啟發的 3D 沙盒動作惡搞網頁遊戲。採用 **HTML5 + Three.js（WebGL 3D 渲染）+ Cannon-es（3D 剛體物理引擎）+ Web Audio API（程序化合成音效與惡搞廣播電台）** 開發。所有 3D 角色、載具、建築與粒子特效皆透過程序化低多邊形（Low-Poly）幾何體與動態 `CanvasTexture` 生成，不依賴任何外部 `.glb` 模型、圖片或音訊檔案。

## 🎮 線上遊玩 / 本地啟動

由於使用原生 ES Modules (`<script type="importmap">`)，請透過本地靜態伺服器或 GitHub Pages 開啟：

```bash
# 方式 1：Python 內建伺服器
python3 -m http.server 8080

# 方式 2：Node.js serve
npx serve . -l 8080
```

開啟瀏覽器前往：`http://localhost:8080`

## 📁 專案結構

- `index.html`：GTA 風格 HUD、圓形雷達小地圖、8 格武器輪盤與雙平台控制介面
- `js/main.js`：遊戲主迴圈、物理步進、攝影機追蹤、1～5 星通緝與雷達潛行消星
- `js/world.js`：室內外無縫 3D 地圖、可撞破落地玻璃門、「水＋電」連鎖機關、碎紙機龍捲風、茶水間微波爐爆炸、巨型滾動 PVC 輸水管與支線任務光圈
- `js/vehicles.js`：可搶奪駕駛的 4 款 3D 載具（渦輪辦公轉椅、倉庫電動堆高機、工務處工程小貨車、高壓清洗水車）
- `js/weapons.js`：8 種惡搞武器、`0.2x` 子彈時間武器輪盤與前方 45 度扇形智慧鎖定
- `js/npc.js`：一般員工、戴假髮的主管與 1～5 星執法單位 AI、動態 `CanvasTexture` 表情與繁體中文對話氣泡
- `js/audio.js`：Web Audio API 合成音效與「FM 98.7 水公司之聲」惡搞廣播電台

## 🕹️ 操作指南

- **`WASD` / 方向鍵**：移動 / 駕駛轉向
- **`Space`**：跳躍 / 載具甩尾手煞 / 高壓水槍滯空飛行
- **`滑鼠左鍵`**：攻擊 / 射擊 / 堆高機貨叉升降 / 水車 360° 高壓水砲
- **`按住 Q`**（或 **`1`～`8`**）：開啟 `0.2x` 子彈時間 8 格武器輪盤
- **`F`**：搶奪駕駛載具 / 下車 / 啟動支線任務光圈
- **`E`**：喝下特濃美式（6 秒咖啡因超頻）/ 引爆遙控微波爐便當炸彈
